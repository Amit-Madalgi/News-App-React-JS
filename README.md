# 📰 NewsMonkey - React News App

NewsMonkey is a responsive React-based news application that fetches and displays the latest headlines from around the world using the NewsAPI. It supports category-wise filtering, loading indicators, and routing for seamless user experience.

## 🔧 Features

- 🗞️ Browse top headlines from different categories
- 🌐 Country-based news fetching (currently set to US)
- 🚀 Fast and responsive UI with a top loading bar
- 🧭 React Router for navigation
- 📦 Environment variable support for API keys
- 🧩 Clean component-based architecture
